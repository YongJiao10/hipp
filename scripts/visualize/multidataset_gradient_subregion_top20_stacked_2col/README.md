# Multi-Dataset & Multi-Cohort Gradient-Spectral Subregion Top-20 Network Composition (2-Column Layout)

The maintained HCP/JJ_TMS comparison has explicit 2mm/36p Standard and
CtxReg signal branches. Kong2022 bars use the normalized Top-20 assignment;
Lynch2024 bars use the positive Fisher-z profile. Comparison surfaces are
rendered from the exact assignment manifest and are checked against the bar
composition, rather than being copied from a reference-worktree PNG. Each
comparison panel and composite has source fingerprints and assignment
provenance. The historical four-cell legacy grid remains available through
the unified runner.

本文档记录跨数据集海马 2mm Gradient-Spectral 群组分区（$K=3$ 亚区：Anterior、Middle、Posterior）与各亚区连接最强 Top-20 皮层靶区的 **Normalized Count（网络容量归一化版）** 的完整图谱与统计数据。

## Additive HCP/JJ_TMS 7-network comparison

The `hcp_jjtms_7net` branch is an additive comparison of Kong2022 7-Network and Lynch2024 7-Network outputs. It preserves the existing two-column layout, dataset background bands, side labels, and Workbench surface rendering; it only replaces the displayed comparison content. Both columns use HCP 7T `N=151`, Iowa HC `N=67`, Iowa Patient `N=26` (sub-3003 excluded), Pure MDD `N=7`, and Comorbid MDD `N=19`.

The Kong2022 column is labelled with the `kong2022_7net` presentation namespace,
but its producer input is explicitly
`gradient-spectral/kong2022` (and `wta-top/kong2022` where WTA assets are
needed). The namespace label never denotes a seven-column gradient input. The
retired `routea_7net` producer namespace is neither read nor regenerated by
this comparison. Active Kong gradient profiles are `(3,400)` and active WTA
profiles are vertex-by-400 ROI arrays.
The two columns intentionally use different source metrics: Kong2022 uses
normalized-top20 count, while Lynch2024 has no ROI-capacity-normalized
top-20 artifact and uses the explicit positive Fisher-z network profile
(`cluster_network_profile.npy` plus `group_feature_summary.json`). Lynch is
never made to look normalized by borrowing Kong artifacts or by falling back
to another file.

For readability, atlas headers show only the source metric (`Normalized Top-20 Count` or `Positive Fisher-z Profile`); bar headers use `Left Hipp.` / `Right Hipp.` to identify the two hippocampal sides without spelling out the full `Hippocampus` word
---

The comparison renderer is fail-closed and method-specific. For Kong2022,
subregion bars must read `cluster_assignment_status_normalized_top20_count.json`
with `assignment_metric=top20_count_normalized_by_network_roi_count`, and the
hippocampal atlas must be cropped from the explicit
`*_normalized_top20_count.png` overview path. For Lynch2024, subregion bars
must read the explicit Fisher-z profile artifacts and the atlas must be cropped
from the `*_fisherz.png` overview path. Missing, malformed, or mismatched
artifacts abort rendering; no method can silently substitute the other
method's metric.

Comparison surface panels write `surface.png` with provenance sidecar
`surface.sources.json` (via `publish_cache`: `png.with_suffix('.sources.json')`);
the composite source lock consumes that exact sidecar path. The CtxReg branch
accepts the pre-`signal_branch` formal HCP Kong contract (`routea_ctxreg`
`shared_root`/`actual_consumed_input_paths` with standard `reference_root`)
through the explicit legacy provenance check shared with the cluster-confidence
renderer; existence order never selects the result.

## 1. 核心问题定位与修复：海马表面图与条形图的 100% 对应一致性

对于 legacy normalized-count 产物，海马表面图与条形图均采用**网络容量归一化（$n_k / N_k^{\text{total}}$）**：

- **Iowa HC 右侧 Middle**：海马表面对应渲染为 **Auditory（青色）**，与条形图中 AUD 占 33% 首位完全吻合！
- **Stanford TEHC 右侧 Middle**：海马表面对应渲染为 **Somatomotor（蓝色）**，与条形图 SMN 首位吻合！
- **Stanford TEHC 左侧 Anterior**：海马表面对应渲染为 **Auditory（青色）**，与条形图 AUD 首位吻合！
- **Stanford NTS 前部**：海马表面对应渲染为 **Language（棕色）**，与条形图 LAN 首位吻合！

海马解剖表面图严格直接从 group overview 图谱中裁切（标准 860×1644 竖版四视角视图），已彻底移除静默降级（fallback）至单被试 Workbench 场景渲染的逻辑，若 overview 产物缺失将严格报错中断，避免比例失调与布局异常。

## 3. 运行与复现指令

海马小图按 `--grid` 的平滑条件裁剪：canonical overview（4620×3660）
上行为 2mm、下行为 4mm。裁剪器验证两个表面区域（黑底 legacy overview
使用边界检测，白底 overview 使用固定的 producer row geometry），再从所选行
裁出 860×1644 解剖视图；legacy 黑底的边界连接背景会统一为白色，解剖前景不改。
若输入是明确的单行 4620×1830 overview，只允许选择 2mm；4mm、缺行、错误尺寸
都直接报错，绝不复用另一行或其他 overview。两种平滑条件共享 overview 文件是
正常的，但必须选择各自对应的行。

正式刷新必须通过统一入口，刷新 2mm/4mm 的 36p 两图。
独立 renderer 命令行入口已移除，直接执行会报错；不再保留单网格诊断例外。
