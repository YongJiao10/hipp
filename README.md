# Hippocampal analysis workflows

Source code, workflow documentation, configuration, environment definitions,
and tests for the hippocampal analysis workflows are maintained here.

- [Workflow documentation](docs/README.md)
- [Core workflow](docs/hipp_parcellation_network/core_workflow_overview.md)
- [Agent runtime contract](docs/environment/agent_runtime_contract.md)
- [GitHub scope and synchronization](docs/github_sync.md)

Datasets, generated images, result tables, caches, installed dependencies, and
archives are stored locally and are excluded from this source repository.
Small diagram input images and Workbench scene configurations are included.
A clone supplies the implementation and its configuration; workflow execution
also requires the external inputs described in the workflow documentation.
