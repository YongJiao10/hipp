# Joint hippocampal parcellation from individual connectivity profiles

## Scientific question and scope

Can a method that retains each participant during boundary fitting produce a better common three-region hippocampal atlas for held-out participants? A separate question is whether a participant's own boundary deviation reproduces across acquisitions. The first question is testable with the current participant-aggregate functional connectivity (FC) matrices. The second requires independent within-person data.

Build two experimental routes alongside the existing HCP comparison in this worktree. Both start with the same participant-level hippocampus-to-Kong2022 cortical ROI FC, and both return a group map at fixed K = 3. Fit each hemisphere separately for Standard, CtxReg 10 mm and CtxReg 20 mm at 2 and 4 mm. Start with Standard at 2 mm as a development condition. Keep each requested result under the worktree's `tmp/subject-aware-parcellation/` during development. Production outputs and selection of the primary atlas are outside this experiment.

## Shen multigraph spectral clustering

1. Use a participant's valid vertices intersected with training support. Construct Pearson similarities over the 400 ROI fingerprints. For a prespecified hippocampal affinity use off-diagonal positive Pearson weights, retain the top 10% of off-diagonal neighbours per row by rank, symmetrize by the arithmetic mean of the two directed weights and set the diagonal to zero. Define the neighbour count as the ceiling of 10% of other observed vertices, ordering equal weights by template ID. Empty positive neighbourhoods or a disconnected graph are reported with the affected participant and graph sizes. This affinity adapts Shen's published optimizer to the project's FC fingerprints. The paper used distances between fMRI time courses.
2. Form the degree-normalized adjacency for each participant, take the K largest algebraic eigenvectors including the leading one, then normalize each vertex row to unit length. Maintain a separate embedding and vertex index for each person. Fit one shared one-hot assignment Y and one orthogonal rotation per participant. Minimize the sum of squared distances between each observed embedding row after rotation and the corresponding row of Y. Restrict each participant's Procrustes update to observed rows. Update Y by the maximum summed aligned score among contributors at each vertex. This observed-row extension reduces to Shen's equations 2–5 under complete coverage.
3. Use ten deterministic seeded starts and select the converged nonempty K solution with lowest training loss. Bound iterations and report unusable starts. Export the joint group assignment and each participant's aligned argmax labels on observed vertices. A disconnected output parcel is a scientific result. Report component sizes on the original mesh.
4. Include a matched single-graph spectral comparator for interpreting Shen: average its training participant affinities edgewise over participants who observed both endpoints (a pruned observed edge contributes zero), degree-normalize, embed and discretize once with the same single-graph routine. This complements the established gradient-spectral and Avg FC/Avg Sim Ward comparisons. Changes relative to the established routes can reflect several algorithmic differences.

## Hierarchical Bayesian parcellation

1. Use the authors' HierarchBayesParcel implementation. The designated py314 environment has PyTorch but does not currently expose this package. Select an explicit upstream version/revision, confirm its API and run the official single-dataset model on a small CPU tensor in an isolated dependency location compatible with py314. Add the verified dependency to the experiment environment documentation before the full fit.
2. Provide a single tensor in participant × cortical ROI × active hippocampal vertex order, with one aggregate fingerprint per person and vertex. Use a single emission model, an identity feature design, the signed Fisher-z profiles with their original across-ROI mean, and the package's unit-length normalization. Use `MixVMF` with one common concentration and `ArrangeIndependent` with a learned location-specific prior. Train arrangement and emission jointly with `FullMultiModel`. Fit L and R independently. This model estimates probabilistic parcel membership and does not impose mesh connectivity.
3. Represent an unobserved vertex as an entirely missing profile. Verify at the pinned upstream version that it supplies zero directional evidence and no observed partition to the emission update. For the independent arrangement an unobserved individual's posterior equals the prior at that location. Mask missing vertices on individual export so prior-only assignments cannot be mistaken for measurements. Check observed profiles have nonzero norm, posteriors sum to one, and training is finite. Use seeded multiple initializations and select by training likelihood only. Pin their number and stopping settings before cross-validation.
4. Save the learned arrangement marginal as the group probability map and its argmax as the group label. Save the final individual posterior and its argmax separately. Preserve the learned emission directions and concentration for later application. Use a single parcel-ID permutation based on the group long-axis order for all labels, both probability arrays and emission directions.
