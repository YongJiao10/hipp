# Joint hippocampal parcellation from individual connectivity profiles

## Scientific question and scope

Can a method that retains each participant during boundary fitting produce a better common three-region hippocampal atlas for held-out participants? A separate question is whether a participant's own boundary deviation reproduces across acquisitions. The first question is testable with the current participant-aggregate functional connectivity (FC) matrices. The second requires independent within-person data.

Build two experimental routes alongside the existing HCP comparison in this worktree. Both start with the same participant-level hippocampus-to-Kong2022 cortical ROI FC, and both return a group map at fixed K = 3. Fit each hemisphere separately for Standard, CtxReg 10 mm and CtxReg 20 mm at 2 and 4 mm. Start with Standard at 2 mm as a development condition. Keep each requested result under the worktree's `tmp/subject-aware-parcellation/` during development. Production outputs and selection of the primary atlas are outside this experiment.

## Shen multigraph spectral clustering

1. Use a participant's valid vertices intersected with training support. Construct Pearson similarities over the 400 ROI fingerprints. For a prespecified hippocampal affinity use off-diagonal positive Pearson weights, retain the top 10% of off-diagonal neighbours per row by rank, symmetrize by the arithmetic mean of the two directed weights and set the diagonal to zero. Define the neighbour count as the ceiling of 10% of other observed vertices, ordering equal weights by template ID. If any observed vertex has zero degree or a participant graph is disconnected after symmetrization, stop that condition/fold and report the participant, affected vertices and component sizes. Use this as an explicit graph criterion for this experiment. Keep the roster and affinity definition fixed. This affinity adapts Shen's published optimizer to the project's FC fingerprints. The paper used distances between fMRI time courses.
2. Form the degree-normalized adjacency for each participant, take the K largest algebraic eigenvectors including the leading one, then normalize each vertex row to unit length. Maintain a separate embedding and vertex index for each person. Fit one shared one-hot assignment Y and one orthogonal rotation per participant. Minimize the sum of squared distances between each observed embedding row after rotation and the corresponding row of Y. Restrict each participant's Procrustes update to observed rows. Update Y by the maximum summed aligned score among contributors at each vertex. This observed-row extension reduces to Shen's equations 2–5 under complete coverage.
3. Use ten deterministic seeded starts and select the converged nonempty K solution with lowest training loss. Bound iterations and report unusable starts. Export the joint group assignment and each participant's aligned argmax labels on observed vertices. A disconnected output parcel is a scientific result. Report component sizes on the original mesh.
4. Include a matched single-graph spectral comparator for interpreting Shen: average its training participant affinities edgewise over participants who observed both endpoints (a pruned observed edge contributes zero), degree-normalize, embed and discretize once with the same single-graph routine. Use the identical training support, rank rule and discretization settings. An unobserved vertex pair contributes neither weight nor count. Stop on a supported pair with no contributors or a group graph that fails the same connectivity criterion. The joint minus single-graph score is the primary Shen contrast. Changes relative to the established routes can reflect several algorithmic differences.

For the primary fit, subtract the mean over the 400 cortical ROIs separately for each observed participant–vertex fingerprint. Express that vector in the same fixed orthonormal basis of the zero-sum subspace for all people and folds (the 399 rows of `scipy.linalg.helmert(400, full=False)` in registry order). Use the identity design in those 399 coordinates and unit-length directions. This preserves Pearson correlation as the dot product of two directions and gives the directional likelihood the dimension of the space being fitted. Verify that identity against the existing Pearson routine. The sensitivity fit uses the original 400 Fisher-z coordinates with unit-length normalization and retains each fingerprint's across-ROI mean. Run this sensitivity on the full hierarchical model at Standard 2 mm, both hemispheres, with the same folds. Report its paired differences separately.

Use one aggregate fingerprint per person and vertex for the primary group-atlas question, with `part_vec=None`. Fit one `MixVMF` emission with a common concentration κ and an `ArrangeIndependent` location-specific prior, jointly in `FullMultiModel`. Each hemisphere has its own fit. The prior is independent across vertices and permits spatially disconnected parcels. Independent per-run fingerprints belong to the repeatability analysis below. Repeating an aggregate fingerprint would supply the model with artificial repeat measurements.

Supply an unobserved participant–vertex as an all-NaN profile. On the pinned version it contributes zero emission evidence, zero observed partitions and zero directional statistics. Its posterior therefore equals the location prior. Mask it on individual export and exclude it from individual diagnostics. ### Bayesian contrasts and outputs

Averaging the participants leaves one observed direction per vertex. With a freely estimated prior at *each* vertex, the arrangement update would set that prior to the posterior of the same single observation. For fixed parcel directions, the next update multiplies the prior odds by the same likelihood ratio again. Such a map cannot estimate between-person parcel frequencies. Use the following three fits to distinguish the effect of averaging from the effect of learning a spatial prior. [Pinned arrangement E- and M-steps](https://github.com/DiedrichsenLab/HierarchBayesParcel/blob/d4031910ebd16e9013d756eef4d057ba7106d64c/HierarchBayesParcel/arrangements.py#L82-L124)

| Fit | Training observations | Prior and group readout |
| --- | --- | --- |
| Group-mean vMF | At each training vertex average the observed participants' centered unit directions with equal weight, then normalize the resultant. Report and stop if the direction is undefined. | Learn one set of mixing proportions shared across vertices (`spatial_specific=False`). Take the per-vertex posterior argmax. |
| Participant-level vMF | Give the same centered unit directions to the emission model as separate participant observations. | Use the same shared mixing proportions model. Average the fitted posteriors over observed training participants at each vertex and take the argmax. |
| Full HierarchBayesParcel | Use the same separate participant observations. | Learn a different set of proportions at each vertex (`spatial_specific=True`). Save the learned arrangement marginal and its argmax, plus each observed participant's posterior and argmax. |

The primary Bayesian contrast for **retaining participant observations** is participant-level vMF minus group-mean vMF. Both fits share the feature basis, common-κ emission family, global mixing-proportions model, initialization budget and support. Start screening with emission evidence (`align=0`) for the global-mixing fits. Full HierarchBayesParcel minus participant-level vMF measures the additional contribution of the learned location prior. Report full model minus group-mean as the total atlas difference. Each fit learns its own parameters from the training half.

For each Bayesian fit report the dimension, κ, and the mean resultant length used by the upstream κ update (before clipping). For the full model also report the distribution of posterior entropy divided by log(K) on observed participant–vertices, the fraction with maximum posterior above 0.99 and the fraction whose winning label changes when the location prior is included relative to emission evidence alone. The estimator depends on both dimension and resultant length. Interpret posterior concentration from the measurements. Preserve fitted directions and concentration, and apply the same group long-axis parcel permutation to labels, probability axes and emission directions. [Pinned concentration update](https://github.com/DiedrichsenLab/HierarchBayesParcel/blob/d4031910ebd16e9013d756eef4d057ba7106d64c/HierarchBayesParcel/emissions.py#L517-L535)
