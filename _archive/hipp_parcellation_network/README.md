- `legacy_subject_pipeline/`: retired subject-level clustering and summary scripts
- `legacy_group_prior/`: retired `group prior + fast-PFM` workflow and related renderers/wrappers
- `legacy_group_methods/`: retired MSHBM experiment code
- `legacy_docs/`: retired multi-branch and instability-era flow docs
- `results/`: archived legacy outputs and presentation exports
